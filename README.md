# 🛡️ Private Cloud SOC Platform

## 📌 Description

Projet de Fin d’Année réalisé chez **Advanced Computer Technology (ACT)**.

Mise en œuvre d’une **plateforme SOC intelligente** dans un environnement **Cloud privé IaaS basé sur Sangfor HCI**, dédiée à la supervision, la détection et la sécurisation des infrastructures.

## 🚀 Fonctionnalités

* ☁️ Déploiement d’un Cloud privé avec Sangfor HCI
* 🛡️ Supervision et détection avec Wazuh SIEM/XDR
* ⚙️ Automatisation des incidents avec Shuffle SOAR
* 🔍 Threat Intelligence avec VirusTotal, AbuseIPDB et AlienVault OTX
* 🚨 Analyse et enrichissement des alertes de sécurité
* 🔒 Blocage automatique des adresses IP malveillantes
* 🖥️ Environnement Windows, Linux et Active Directory
* 📊 Monitoring des événements de sécurité
